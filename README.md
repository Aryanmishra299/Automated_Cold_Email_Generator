## 📌 Project Summary

The **Automated Cold Email Generator** is a Generative AI-based application designed to streamline the job application process by eliminating the need to manually write repetitive cold emails.

The system intelligently analyzes job postings, extracts key requirements, and generates highly personalized professional emails tailored to each role.

---

## 🎯 Key Objectives

- Automate cold email writing for job applications  
- Improve personalization using AI-driven context understanding  
- Reduce manual effort in job search outreach  
- Match candidate portfolio/projects with job requirements  

---

## ⚙️ How It Works

The system follows a structured AI pipeline:

### 1. URL Input
User provides a job posting or career page URL.

### 2. Web Scraping
Job description and relevant content are extracted from the webpage.

### 3. Data Processing
Raw text is cleaned and processed using NLP techniques.

### 4. AI Analysis (LLM)
The language model extracts structured information such as:
- Job Role  
- Required Skills  
- Experience Level  
- Responsibilities  

### 5. Portfolio Matching (Vector Search)
Relevant projects are retrieved using semantic similarity search.

### 6. Email Generation
A personalized cold email is generated using LLM based on:
- Job context  
- Candidate profile  
- Matched projects  

### 7. Output
Final email is displayed in the Streamlit interface.
